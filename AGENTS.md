# Source Repository Agent Entry Point

Project instructions, architecture, plans, and workflows live in the companion
`RGBMatrix_Agents` repository checked out beside this repository.

Before working here, read `../RGBMatrix_Agents/AGENTS.md` and follow it. For an
active project, also read its `SCOPE.md`, `STATE.md`, and latest `handoff.md` as
directed there. Runtime code and current evidence in this repository take
precedence if documentation has drifted.

If the companion checkout is unavailable, report that before changing source or
touching the Raspberry Pi; do not infer the hardware or deployment procedure.
