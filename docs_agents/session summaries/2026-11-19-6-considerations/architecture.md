# Architecture status

No runtime architecture changes in this cleanup.

The active target remains the compiled analyzer registry and ordered layer plan in
`2026-11-19-5`, with manually selected direct and SetImage backends. A separate
matrix process remains an early experiment within that roadmap, not an accepted
topology.

The sketches in [README.md](README.md) are nonbinding. In particular, they do not
approve time-based animation, new pacing, shared memory, a native binding rebuild,
or a general compositor.
